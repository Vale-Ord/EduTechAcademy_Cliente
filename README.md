# EduTechAcademy · Página para el cliente

Sitio estático (un solo `index.html`) que explica el sistema de inscripción y certificación
y permite probar todas las acciones de la API con mensajes para el cliente.

## Despliegue en Render
1. Sube esta carpeta a un repositorio nuevo de GitHub (por ejemplo `EduTechAcademy_Cliente`).
2. En Render: **New +** → **Blueprint** → elige el repositorio → **Apply**.
   (También sirve **New +** → **Static Site**, Build Command vacío y Publish Directory `.`)
3. Al terminar, Render da una URL pública `https://edutech-academy-cliente.onrender.com`.

No requiere variables de entorno ni base de datos.
